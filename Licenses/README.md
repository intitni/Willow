# License material

`Overrides` preserves notices omitted from some published crate archives.
`Overrides/SOURCES.json` records the corresponding upstream URLs. The rquickjs
core, macro, and sys overrides use the workspace license shipped in rquickjs 0.12.2
(the same release and authors); the sys fork also includes its own QuickJS notices.
The srcmap workspace license applies to codec, scopes, and sourcemap 0.3.9.

`Standard` contains unmodified license terms for packages whose manifests declare
those licenses but whose published archives omit the license file. Attribution
uses the upstream package metadata, without inventing copyright ownership or dates.
These texts do not assign a license to Willow's original code.
